> **Platform Key:**
> 🟠 LeetCode | 🔵 GeeksForGeeks (GFG) | 🟣 Coding Ninjas | ⚫ InterviewBit

## How to Use This Roadmap

| Session Block | Time | Activity |
|---|---|---|
| Warm-up | 15 min | Solve 1 Easy problem |
| Learn | 45 min | Study one pattern with notes |
| Practice | 60–90 min | Solve 2–3 new problems |
| Review | 20 min | Revisit one old problem, explain aloud |

## Interview Patterns Cheat Sheet

| Pattern | When to Use | Key Clue in Problem |
|---|---|---|
| Sliding Window | Contiguous subarray/substring | "longest", "shortest", "at most k" |
| Two Pointers | Sorted array, pair/triplet sum | "sorted", "pair", "target sum" |
| Binary Search | Sorted structure or monotonic answer | "minimum maximum", "feasible" |
| BFS | Shortest path, level order | "shortest path", "minimum steps" |
| DFS/Backtracking | All solutions, permutations | "all combinations", "generate all" |
| DP | Overlapping subproblems | "number of ways", "min cost", "max profit" |
| Greedy | Locally optimal = globally optimal | "minimum number of", "maximum at each step" |
| Union Find | Connectivity, grouping | "connected components", "same group" |
| Monotonic Stack | Next greater/smaller element | "next greater", "span", "histogram" |
| Heap | K-th largest/smallest, streaming | "top K", "K closest", "median" |
| Trie | Prefix search, autocomplete | "starts with", "prefix", "word search" |
| Morris Traversal | O(1) space tree traversal | "without extra space", "O(1) memory" |
